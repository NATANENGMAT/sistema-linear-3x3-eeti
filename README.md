# 📐 Sistema Linear 3x3 - Plataforma Interativa

Plataforma educativa interativa desenvolvida para alunos da **EETI Bilíngue Profª. Jacimar Da Silva Gama**, Turma **2º 4**, sob orientação do **Prof. Natanael de Matemática**.

## 🎯 Objetivo
Facilitar a compreensão introdutória de **Sistemas Lineares 3x3** para alunos com defasagem na aprendizagem, utilizando:
- Linguagem simplificada e analogias práticas (sem uso de índices).
- Quiz interativo mobile-first com 8 questões e feedback pedagógico imediato.
- Acompanhamento em tempo real das entregas e notas pelo painel do professor.

## 🚀 Como Executar
1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor:
   ```bash
   npm start # ou node server.js
   ```
3. Acesse:
   - **Alunos (Mobile):** `http://localhost:3000/`
   - **Professor (Painel):** `http://localhost:3000/professor`
