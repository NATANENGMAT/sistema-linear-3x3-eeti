1. O que é um Sistema 3x3?

Pense como um jogo de adivinhação. Você precisa descobrir o valor de 3 mistérios (3 letras: x, y, z).

3 Letras
3 coisas desconhecidas
3 Linhas
3 pistas com igual (=)
Exemplo de Sistema 3x3:
x + y + z = 12
2x - y + z = 9
x + 2y - z = 3
⚡

2. A Regra do "Linear"

Para ser LINEAR, as letras têm que ser puras e simples. Sem firulas matemáticas!

✅ PODE: letras normais como x + y ou números multiplicando como 3x, 5y.
❌ NÃO PODE: expoente (x²), letras multiplicando juntas (x · y) ou raiz (√x).
🔤

3. As letras podem mudar!

Não precisa ser sempre x, y e z! Qualquer grupo de 3 letras serve:

Com x, y, z: x + y + z = 10
Com a, b, c: 2a + b - c = 5
Com m, n, p: m - n + 3p = 8
